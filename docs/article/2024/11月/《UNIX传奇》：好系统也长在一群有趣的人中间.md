# 《UNIX传奇》：好系统也长在一群有趣的人中间

2024 年 11 月读完。

以前提到 UNIX，我首先想到的是命令、管道、C 语言和操作系统。读完这本书，印象更深的反而是贝尔实验室里那群人。他们并不是每天端坐着规划一项注定改变世界的工程，许多东西是在一起工作、一起玩、互相欣赏的环境里慢慢长出来的。

我很喜欢书里谈到“乐趣”的部分。理想的工作大概不只是工资和职位，而是身边有一群厉害又愿意交流的人，大家真的享受把问题弄明白的过程。UNIX 和 C 后来影响了 CPU 的设计，这是典型的“上层驱动下层”；而它们最初又受限于机器内存、磁盘和终端。技术就是这样一层一层互相塑造，并没有绝对孤立的一层。

还有“第二系统效应”也很有意思：第一个系统成功后，总想在第二个系统里修完所有遗憾，再塞进所有人期待的功能，最后反而变得臃肿。做业务系统时，这种冲动太熟悉了。过度设计往往不是能力不够，而是太想一次把未来也解决掉。

传奇背后的故事总让人感慨。真正留下来的技术，除了天才和条件，可能还需要一点朴素的东西：兴趣、自由，以及和对的人一起工作的运气。
