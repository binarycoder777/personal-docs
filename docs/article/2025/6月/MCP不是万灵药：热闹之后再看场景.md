# MCP 不是万灵药：热闹之后再看场景

2025 年 6 月读完这篇轻科技。

MCP 火起来以后，几乎一夜之间成了 Agent 相关讨论绕不开的词。统一工具接入协议当然有价值，`streamable HTTP` 替代原来的 SSE transport，也说明它仍在快速变化。但协议解决的是连接方式，不会顺手解决数据质量、权限、安全和业务设计。

我记下书里一句话：技术史上从不缺少“神话”，真正的进步往往从祛魅之后开始。新技术最热的时候，人们容易先问“能不能接 MCP”，却忘了问这个场景为什么需要 Agent、接入后省了什么、又引入了哪些风险。

技术最终还是要服务场景。MCP 值得学习，也值得使用，只是没必要把它想成所有工具调用问题的终点。热闹的时候保持兴趣，落地的时候保持清醒，可能更重要。
